# اپلیکیشن فیت سنتر — راهنمای اجرا (رایگان، بدون نیاز به اشتراک)

## چیزهایی که لازم داری (همه رایگان)
1. یک لپ‌تاپ (ویندوز یا مک)
2. نصب **Node.js** روی لپ‌تاپ: از سایت nodejs.org نسخه LTS رو دانلود و نصب کن
3. نصب اپلیکیشن **Expo Go** روی گوشی موبایلت (از گوگل‌پلی یا اپ‌استور، رایگان)

## مرحله ۱: اجرای پروژه روی لپ‌تاپ
1. این پوشه (fitcenter-app) رو جایی روی لپ‌تاپت قرار بده
2. یک ترمینال (Command Prompt / Terminal) باز کن و به این پوشه برو:
   ```
   cd path/to/fitcenter-app
   ```
3. نصب پکیج‌ها (فقط بار اول لازم است، به اینترنت نیاز دارد):
   ```
   npm install
   ```
4. اجرای پروژه:
   ```
   npx expo start
   ```
5. یک کد QR روی ترمینال ظاهر می‌شود.

## مرحله ۲: دیدن اپ روی گوشی
1. گوشی و لپ‌تاپ باید به یک وای‌فای وصل باشند
2. اپلیکیشن Expo Go رو باز کن
3. کد QR رو با همون اپ اسکن کن
4. اپ فیت سنتر مستقیم روی گوشیت باز می‌شود — دقیقاً مثل یک اپ واقعی نصب‌شده

هر تغییری که در کد بدهی، با ذخیره کردن فایل، بلافاصله روی گوشی هم آپدیت می‌شود (Live Reload).

## اضافه کردن گیف‌های حرکات
1. فایل‌های گیف رو با همون اسم فارسی حرکت (طبق فایل EXERCISES_DATA.md) داخل پوشه:
   ```
   src/assets/gifs/
   ```
   کپی کن.
2. در فایل `src/data/exercises.js`، برای هر حرکت به‌جای `gif: null` این‌طور بنویس:
   ```js
   media: { gif: require('../assets/gifs/پرس سینه هالتر.gif') }
   ```
   (به ازای هر حرکت، اسم فایل مربوط به خودش)

## ساخت اپ نهایی قابل نصب (APK / نسخه اپ‌استور)
وقتی همه‌چیز آماده و تست شد، با دستور زیر (رایگان، فقط نیاز به ثبت‌نام حساب Expo دارد) می‌تونی خروجی نصبی بگیری:
```
npx eas build --platform android
```
این دستور یک فایل APK واقعی می‌سازه که می‌تونی مستقیم روی گوشی نصب کنی یا برای انتشار در گوگل‌پلی استفاده کنی. برای iOS هم مشابه همین با `--platform ios` (نیاز به حساب توسعه‌دهنده اپل داره که هزینه دارد).

## ساختار پروژه
```
fitcenter-app/
├── App.js                     ← نقطه شروع اپ
├── EXERCISES_DATA.md          ← مرجع کامل متن حرکات (برای رجوع)
└── src/
    ├── theme.js                ← رنگ‌بندی اپ
    ├── data/exercises.js       ← تمام دیتای حرکات + اطلاعات باشگاه
    ├── navigation/RootNavigator.js  ← منوی پایین و صفحات
    ├── screens/                ← صفحات اپ (لیست حرکات، جزئیات، برنامه، تغذیه، درباره ما)
    └── assets/gifs/            ← اینجا گیف‌ها رو بریز
```
